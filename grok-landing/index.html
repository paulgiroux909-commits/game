Leading use cases

Implied by where Grok lands on the matrices — not by marketing slogans.

  1. Coding agents at fleet scale Coding Index parity with GPT-5.5 at ~half the task cost and ~3× fewer tokens. Best when token volume dominates spend.
  2. Tool-heavy multi-step agents #1 τ³-Banking. Customer ops, banking-style tool chains, orchestrators with many tool calls per turn.
  3. Knowledge-work agents on a budget GDPval Elo in the Opus neighborhood at a fraction of Opus $/task. Research / ops agents where Fable would overspend.
  4. Vertex “default frontier” lane Against Gemini ($2/$12) and Claude partners ($2–10 / $10–50), Grok is the intelligence-per-dollar default.
  5. High-throughput reasoning Fastest measured output speed in this peer set (~118 t/s) with concise token use — better for parallel agent swarms.
Caveats: Absolute peak remains Fable 5 (and newer GPT-5.6 Sol on the live board). AA-Omniscience accuracy rose, but hallucination rate also rose (25% → 54%) — add retrieval/verification for factual work. Context is 500K (down from Grok 4.3’s 1M). Prefer Gemini/Claude when you need a full 1M window on Vertex today.
