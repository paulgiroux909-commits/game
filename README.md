# Grok 4.5 ecosystem brief

Static landing page comparing **Grok 4.5** to frontier models and Vertex AI peers using Artificial Analysis benchmarks and published pricing.

## Run locally

Open `grok-landing/index.html` in a browser, or from the repo root:

```bash
python3 -m http.server 8080 --directory grok-landing
```

Then visit `http://localhost:8080`.

## What’s covered

1. **Frontier ranking** — Intelligence Index + list pricing vs Fable 5, Opus 4.8, GPT-5.5
2. **Vertex AI comparison** — assumed Grok 4.5 availability vs Gemini 3.1 Pro, Claude partners, Llama 4 Maverick
3. **Leading use cases** — where Grok’s rank implies the sell (agents, coding, intelligence-per-dollar)

## Note

Grok 4.5 is not yet on Vertex AI; the Vertex section assumes SpaceXAI list pricing ($2 / $6 per 1M tokens). Sources are linked in the page footer.
