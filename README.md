# H5 Dungeon Roguelite Demo

A zero-dependency HTML5 roguelite prototype. Open `index.html` directly or run a local static server:

```bash
npm start
```

Then visit <http://localhost:4173>.

## Demo Features

- Canvas-based first-floor dungeon run with six rooms.
- Unique monster packs, a neighborhood boss, and a floor boss.
- Weighted loot rarity tiers: common, rare, ultra rare, legendary, and celestial.
- Equipment slots for head, chest, hands, legs, boots, necklace, charms, and both hands.
- Inventory menu with equip actions and active synergy tracking.
- Level-up stat picker using classic crawler stats.
- Whacky event rooms with charisma/luck-influenced outcomes.
- Difficulty scaling that expects meaningful loot and synergy choices.

This prototype uses original placeholder lore and names while preserving the requested roguelite systems and chaotic dungeon-show tone.
