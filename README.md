# Grok 4.5 ecosystem brief

Data-focused static page comparing **Grok 4.5** to frontier models and Vertex AI peers using Artificial Analysis benchmarks and published pricing.

## Preview

```bash
python3 -m http.server 8080 --directory grok-landing
```

Open [http://localhost:8080](http://localhost:8080) — or just open `grok-landing/index.html` in a browser.

## Contents

- **Dual-factor matrices:** intelligence vs cost, speed, list price, and tokens; coding agent score vs cost and tokens (golden zones marked)
- **Frontier table** with AA Index, $/task, speed, and coding economics
- **Vertex AI matrix** (Grok 4.5 availability assumed at $2 / $6)
- **Use cases** implied by where Grok sits on the Pareto plots
